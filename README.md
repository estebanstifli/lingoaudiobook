# LingoAudioBook — web

Web pública de la app Android LingoAudioBook (GitHub Pages): presentación, ayuda, contacto y política de privacidad.

- https://estebanstifli.github.io/lingoaudiobook/ — inicio (inglés) · `es/` (español)
- https://estebanstifli.github.io/lingoaudiobook/privacy/ — política de privacidad (inglés y español). Es la URL que
  se declara en Play Console y la que abre la app (Ajustes › Acerca de).

HTML estático, sin compilación. Al cambiar la política, actualizar la fecha de entrada en vigor.
